# 国考十年真题分类训练

一个面向国考行测备考的静态练习网站，按考点组织 **2016—2026 年（含首尾，共 11 年）**的资料分析与判断推理真题，支持阅读原卷图表、独立作答和查看参考解析。

**在线练习：** [资料分析](https://tswcbyy7268.github.io/kaogong-10years-exam/) · [判断推理](https://tswcbyy7268.github.io/kaogong-10years-exam/judgment.html)

## 题库范围

当前题库覆盖 27 套试卷，包含副省级、地市级、行政执法试卷类型；具体年份与试卷组合以页面筛选结果为准。

| 模块 | 收录数量 | 分类方式 |
| --- | --- | --- |
| 资料分析 | 325 个训练条目，由 540 道题次合并得到 | 9 类考点 |
| 判断推理 | 1050 道题次，按原卷编号分别收录 | 4 大题型、43 类专项 |

资料分析将同年、同材料、同一提问的重复题合并，题目中标注同题出处。判断推理按试卷分别收录，不同试卷可能包含同一道题，因此题次数量不代表去重后的独立题目数量。

### 资料分析

读数与现期计算、基期量、增长量、增长率、比重与比例、平均数与单位量、倍数与比值、预测与其他应用、综合判断。

### 判断推理

| 题型 | 题次数 | 专项分类数 |
| --- | --- | --- |
| 图形推理 | 270 | 15 |
| 定义判断 | 270 | 6 |
| 类比推理 | 240 | 13 |
| 逻辑判断 | 270 | 9 |

判断推理页面提供题型总结，包括识别线索、解题方法，以及部分专项的训练能力和常见误区。

## 主要功能

- **分类练习：** 按考点选择题目，判断推理可先选择大题型再进入专项。
- **组合筛选：** 按年份、试卷出处筛选，并搜索题干、年份或题号。
- **原卷阅读：** 查看原题、材料与图表，切换原卷页码，定位当前题目并放大图片。
- **作答反馈：** 选择 A/B/C/D 后提交，与参考答案核对；支持重新作答。
- **参考解析：** 答案默认收起，可按需展开解析图片、来源信息与专项方法提示。
- **连续训练：** 支持题目列表分页，以及在筛选结果中切换上一题、下一题。

作答记录保存在当前页面的内存中。刷新页面或切换模块后会重置，当前版本没有账号登录、云端同步或持久化错题本。

## 使用方法

1. 打开在线练习页面，选择资料分析或判断推理模块。
2. 选择考点，按需要筛选年份、试卷出处或输入关键词。
3. 阅读原卷材料与选项；材料跨页时切换页码，图片较小时点击放大。
4. 选择答案并提交，再展开参考解析核对思路。
5. 用“上一题”“下一题”继续练习，或重新作答复盘。

## 本地运行

项目使用原生 HTML、CSS 和 JavaScript，无需安装前端依赖或执行构建命令。

### 直接打开

在仓库页面选择 **Code → Download ZIP**，解压后用现代浏览器打开 `index.html`；判断推理入口为 `judgment.html`。请保留完整目录，尤其是两个图片资源文件夹。

### 使用本地静态服务器

已安装 Git 和 Python 3 时，可执行：

```bash
git clone https://github.com/tswcbyy7268/kaogong-10years-exam.git
cd kaogong-10years-exam
python -m http.server 8000
```

然后访问 [http://localhost:8000](http://localhost:8000)。Windows 上如果使用 Python 启动器，也可执行 `py -m http.server 8000`。

## 文件结构

```text
kaogong-10years-exam/
├── README.md             # 项目说明
├── index.html            # 资料分析练习页面
├── judgment.html         # 判断推理练习页面
├── styles.css            # 两个模块共用的样式
├── app.js                # 资料分析筛选、作答与解析交互
├── data.js               # 资料分析题库与考点数据
├── assets/               # 资料分析原卷与解析图片
├── reasoning-app.js      # 判断推理筛选、题型总结与作答交互
├── reasoning-data.js     # 判断推理题库与专项数据
└── reasoning-assets/     # 判断推理原卷与解析图片
```

两个题库文件分别将数据挂载到 `window.BANK`，由各自页面加载；每个页面只加载对应模块的数据和交互脚本。

## 维护与纠错

- 修改界面或交互时，编辑对应 HTML、JavaScript 文件或共用的 `styles.css`。
- 修改题库时，同步核对题目 ID、考点、年份、试卷、原卷编号、答案与图片路径，并更新分类计数及相关汇总信息。
- 新增或替换图片时，保持数据中引用的相对路径与实际文件一致。
- 提交前检查两个模块的筛选、作答、解析展开和图片放大功能。
- 发现题目、答案或分类问题，可在 [Issues](https://github.com/tswcbyy7268/kaogong-10years-exam/issues) 中提供模块、年份、试卷类型、题号和问题描述。

## 题目与答案说明

原题及参考解析来自整理所用的试卷与答案文件，页面中标注相应来源。部分试卷为回忆版，参考答案不等于官方答案；遇到争议题，请结合原始材料核对。
